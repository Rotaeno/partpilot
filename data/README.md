# 合成演示目录

`catalog.json` 为本项目独立编写的虚构目录：3 台演示设备、72 条配件记录。没有读取、改写或脱敏企业底库；设备代号、零件编号、尺寸、重量、适配关系均为教学设定，不能作为采购或维修依据。

## 重建和验证

从项目根目录执行：

```powershell
.venv\Scripts\python scripts\generate_catalog.py
.venv\Scripts\python scripts\generate_catalog.py --check
.venv\Scripts\python -m pytest tests\test_catalog.py -q
```

生成器仅使用 Python 标准库，不联网，不读 PRD，也不调用模型。正常运行只覆盖 `data/catalog.json`；`--check` 只读验证 schema 与重建一致性。修改目录时应修改生成器配方，再重建，避免手改 JSON 后失去可复现性。

## 设计用途

- `DEMO-EX-001`、`002`、`003` 分别为虚构轻型、中型、重型挖掘机；每台各有 24 条主属记录，中型另共享 3 条轻型紧固件。
- `PP-1001` 为设备 001 的玻璃纤维液压回油滤芯，1.2 kg；`PP-1002` 为同设备不锈钢液压回油滤芯，2.4 kg；`PP-1003` 为液压滤清器总成，5.6 kg。前两者层级路径指向总成，便于演示“要滤芯，不要总成”。
- 同名滤芯、液压泵、电磁阀、密封圈跨设备具有不同规格，支持演示设备切换后旧候选失效。
- 别名覆盖“回油滤”“空滤”“泵密封包”“O型圈”“螺丝”等口语表达；关键词匹配能力不等于语义向量检索。
- 每台均有空气滤芯内芯、机油压力传感器、油箱呼吸器共 3 条未知重量，合计 9 条；未知值用 JSON `null` 表达。设备 003 的泵密封组件还缺少外廓尺寸。
- 重量单位统一为 kg；尺寸为三维外廓 mm，仅供演示过滤和单位归一化。密封组件尺寸指包装外廓。
- `assembly_path` 是主要装配位置的演示路径，共用件仍显示主属设备路径，不代表完整 BOM，也不是爆炸图位置核验。

## 图片边界

本目录没有产品照片或真实配件图。`illustration` 是 9 类通用机械示意图标的键，对应 `static/illustrations/*.svg`。图标由本项目直接绘制，标记为“合成示意，非产品照片”；它不表达真实几何、材料、接口或装配关系。无产品照片的记录仍必须参与文字检索。

## 已知局限

这个小目录用于验证 Agent 状态、确定性查询、条件变更、无结果诊断和确认写入流程，不能据此报告工业检索精度、真实设备兼容性或生产用户效果。未来使用更大数据集时，需保留独立评测样本及数据授权说明。
